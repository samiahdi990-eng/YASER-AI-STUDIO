راه‌اندازی ربات در Railway

۱) در Railway وارد سرویس شوید و به Variables بروید.
۲) این متغیرها را اضافه کنید:
   API_ID               شناسه عددی API تلگرام
   API_HASH             هش API تلگرام
   BOT_TOKEN            توکن ربات اصلی
   ROOT_ADMIN           آیدی عددی مدیر اصلی
   PREMIUM_BOT_TOKEN    اختیاری؛ فقط اگر ربات ایموجی پرمیوم جداگانه دارید
۳) در Deployments یک Deploy جدید انجام دهید.
۴) دستور اجرا از railway.json خوانده می‌شود: python -u bot.py
۵) این پروژه یک Telegram worker است و برای اجرا نیازی به متغیر PORT یا دامنه عمومی ندارد.
۶) برای نگهداری bot_data.json پس از Deploy مجدد، یک Railway Volume بسازید و DATA_FILE را به مسیری داخل Volume تنظیم کنید؛ مثلاً /data/bot_data.json (مسیر باید با mount path ولوم یکسان باشد).

نکته امنیتی: توکن‌هایی که در نسخه قبلی سورس قرار داشتند افشا شده‌اند؛ پیش از اجرا آن‌ها را در BotFather باطل و توکن تازه بسازید. مقادیر واقعی را در چت یا فایل عمومی قرار ندهید.
